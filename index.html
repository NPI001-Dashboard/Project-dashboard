Status rules: a subtask is Completed when its planned finish is before today's date. A task has started when any of its subtasks has started or finished. The remaining subtasks of a started task are In Progress. A task with nothing started is Not Initiated. A task is Overdue when it is not fully completed and today is later than its first start date plus the Days entered for it in the sheet (calendar days). Kick Off Meeting has no subtasks or dates, so it is not counted. A subtask with no Start date takes the Finish date of the subtask above it in the same task as its start. Days used are counted in calendar days from that start (the start day counts as day 1) until the subtask's finish date, or until today while it is still running. A running subtask is flagged as exceeded when its days used are more than the specified days in the "STD Required Days" column of the sheet; subtasks with 0 specified days are not checked.
