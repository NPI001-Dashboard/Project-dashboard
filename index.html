Status rules: a subtask is Completed when its planned finish is before today's date. A task has started when any of its subtasks has started or finished. The remaining subtasks of a started task are In Progress. A task with nothing started is Not Initiated. A subtask with no Start date takes the Finish date of the subtask above it in the same task as its start. Days used by a subtask are counted from that start (the start day is day 1) until its finish date, or until today while it is still running. A task has exceeded its specified days when it is not fully completed and the days used since its first start date are more than the specified days for that task. Kick Off Meeting has no subtasks or dates, so it is not counted.
