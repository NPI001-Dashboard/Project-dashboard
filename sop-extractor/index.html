SOP Fixture Extractor

SOP file upload karein: Fixture code, English Description aur Quantity nikal kar milegi. File aapke browser me hi process hoti hai.

1. Translation setting

Key sirf is browser ke localStorage me save hoti hai. Translation ke waqt sirf description ka text bheja jata hai, poori file nahi.

2. SOP file

Yahan SOP file drop karein ya click karke chunein
PDF, Excel (.xlsx/.xls/.csv) ya Word (.docx)

3. Result

Columns "Auto" par theek pehchane jate hain. Agar galat lage to yahan se sahi column chun lein.

S. No.Fixture codeDescription (English)QTY

Kisi bhi cell par click karke edit kar sakte hain. Galat row ko × se hata dein. Description par mouse le jaen to original text dikhega.

File se padhi gayi raw rows dekhein (agar extraction galat lage)
