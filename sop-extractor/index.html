SOP Fixture Extractor

SOP file upload karein: Part Code, English Description aur Quantity nikal kar milegi. File aapke browser me hi process hoti hai.

1. Translation setting

Key sirf is browser ke localStorage me save hoti hai. Translation ke waqt sirf description ka text bheja jata hai, poori file nahi.

2. SOP file

Yahan SOP file drop karein ya click karke chunein
PDF, Excel (.xlsx/.xls/.csv) ya Word (.docx)

3. Result

Part CodeDescription (English)Qty

Kisi bhi cell par click karke edit kar sakte hain. Galat row ko × se hata dein.

Padhi gayi raw lines dekhein (agar extraction galat lage)
